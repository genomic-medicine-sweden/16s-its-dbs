# 16S/ITS database scripts and builds

This repository aims to collect build scripts and configurations for different
versions of customized 16S and ITS-databases used across Genomic Medicine
Sweden, to facilitate sharing and re-use of curation work already done.

Eventually the goal is to reach consensus about a good common database, so that
data will become comparable across sites withing GMS, but the infrastructure
will allow storing and using different versions here while we are working
towards that vision.
